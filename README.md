# Starts Journey

Entertainment, lifestyle, and creator-economy stories. A React + TypeScript + Vite site styled with Tailwind CSS v4.

## Stack

- React 19 + React Router 7
- Vite 7 + `@vitejs/plugin-react`
- Tailwind CSS v4 (`@tailwindcss/vite`)
- Framer Motion, Lucide icons

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
npm run preview # preview the production build locally
```

## Content

Articles and categories are static mock data in `src/data/articles.ts` — replace with a real data source (e.g. Supabase, already listed as a dependency) when ready.
